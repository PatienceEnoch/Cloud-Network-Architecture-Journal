# Network Analytics

A place for notes about reading network behavior from evidence rather than assumptions.

Topics I am building out here include:

- convergence events
- latency, jitter, and packet loss
- route churn and flaps
- traceroute interpretation
- telemetry and incident evidence
- failure-pattern analysis

Related project: [Network Flight Recorder](https://github.com/PatienceEnoch/network-flight-recorder)
